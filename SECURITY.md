# Security Policy

## Reporting a Vulnerability

Please do not open a public issue to report a security vulnerability. Instead use the GitHub's built-in reporting process:

1. Navigate to the [Security and quality](https://github.com/bryanjimenez/nmemonica/security) tab on the main repository page.
2. Click the Report a Vulnerability button.
3. Fill the details.

### Report Details
When making a report please include:
1. Vulnerability description and impact
2. Steps to reproduce issue
3. Basic device information if relevant (Desktop vs Mobile, OS, Browser)
4. Any proposed solutions and or related vulnerability solutions

## Response Time
We will acknowledge the vulnerability report within five business days and implement a solution to the issue or provide an plan of action within 30 business days.

## Scope
This policy applies to vulnerabilities within this repository, in the case the vulnerability is of a dependency please refer to the dependency's project page.
